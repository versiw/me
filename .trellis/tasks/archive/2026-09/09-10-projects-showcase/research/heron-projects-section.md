# 参考区规格:heronaiapp.com「Your design tools do what you tell them, nothing more」

> 证据来源:用户 2026-09-10 提供的原站截图(3824×1844)。原站无法直接抓取(网络策略拦截),以下为截图提取的结构规格。

## 顶部标题区

| 元素 | 规格 |
|---|---|
| 大标题 | 超大号无衬线粗体、全大写、跨两行,占左侧约 50% 宽,起始于分区左边缘 |
| 说明段落 | 右侧约 25% 宽、3 行小字、常规权重,与大标题顶部对齐 |
| 品牌色小方块 | 说明文字下方偏左,约 12×12px,品牌橙红 |

## 主体栅格

- 4 列等宽,列间为**实线**竖分隔,贯穿列高
- 每列自上而下:
  1. **标签行**:mono 大写短标签(左,深色)+ `[0N]` 序号(右,浅灰),同一基线
  2. **虚线横分隔**
  3. **视觉区**:原站为细线几何图形(圆柱+六边形 / 圆+立方体 / 同心圆+立方体 / 层叠六边形),占据列内最大高度
  4. **虚线横分隔**
  5. **大号粗体标题**(全大写,2–4 行)+ 常规小字描述(2–3 行,浅灰)

## 与原站的差异(用户指定)

- 视觉区**不放几何线框图形**,改为放置项目图像;当前无素材,先用文本占位。

## 映射到本项目的 token

| 参考区元素 | 本项目实现 |
|---|---|
| 实线竖分隔 | `col-divide`(≥64rem 转左边线) |
| 虚线横分隔 | 新增 `line-dash-t` / `line-dash-b` |
| mono 标签 / `[0N]` | `font-mono` + `uppercase` + `tracking-[0.08em]` + `text-xs`(与既有 Skills 分区的 `STACK · 12 TOOLS` 写法一致;原站为 0 字距,本项目沿用站内既有字距以保持整站统一) |
| 大号粗体标题 | `font-brand font-bold` + 负字距(对齐 Skills 区标题用法) |
| 浅灰描述 | `text-secondary` / `text-terriary` |
| 品牌色小方块 | `bg-brand`(`--color-brand: #fa3600`) |
| 纸色底 | `bg-paper` |
