## Development

本项目用 Vite+(vp CLI)管理依赖与命令,一律走 `vp`,不要直接用 pnpm/npm(直接调用 pnpm 会因 packageManager 版本约束报错):

```bash
vp i                        # 安装依赖
vp i <pkg>                  # 添加依赖
vp rm <pkg>                 # 移除依赖
vp run dev                  # 启动 dev server(= astro dev,可加 --background 后台运行)
vp run check                # 类型检查(= astro check)
vp run build                # 构建(= astro build)
vp run preview              # 预览构建产物
vp check                    # 格式/lint/type 综合检查
vp lint / vp fmt            # lint / 格式化
vp env                      # 管理 Node 版本(工具链由 vp 负责)
```
